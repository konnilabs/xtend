# XTend-Scaffold Utils

Dieser Bereich enthaelt pure Helfer fuer `XTend-Scaffold`.

- `naming.js`: Tag-Normalisierung, Komponentenname, Klassenname und Tokenersetzung
- `validation.js`: deterministische Eingabevalidierung fuer Component-Plans

Grenze in `WP-E03-04`: Helfer duerfen Pfade, Validierung, Plan-Ausgabe und spaeter Konfliktpruefung kapseln, aber keine versteckten Schreibzugriffe einfuehren.
