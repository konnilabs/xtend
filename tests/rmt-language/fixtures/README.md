# RMT Language Regression Fixtures

- Workpackage: `WP-E14-13`
- Contract: `xtend.rmt.language-regression-matrix.v1`
- Primaerer Dateityp: `.rmt`

Diese Fixtures decken den Long Tail des RMT Toolings ab:

- valide native `.rmt` Dokumente
- fehlende Referenzen
- Duplicate IDs und Duplicate Route Paths
- Syntaxfehler
- `.rmt.json` Fallback-Kompatibilitaet
- groessere Route-/Component-/Template-Matrizen

Neue Fixtures sollen Diagnosecodes pruefen, nicht nur pauschal auf Failure testen.
