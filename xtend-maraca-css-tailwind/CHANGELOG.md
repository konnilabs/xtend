# Changelog

All notable changes to `@xtend-material/maraca-tailwind` are documented here.

## 0.1.0 - 2026-07-16

- Introduced the air-gapped Maraca CSS provider lifecycle.
- Added a memory-only Tailwind CSS 4.3.2 Node toolchain with explicit source ownership.
- Added static RMT `xtm-*` inventory validation and blocking diagnostics for unsafe syntax.
- Added deterministic build, supply-chain and design-kit fingerprints.
- Added native-provider exit evidence and a zero-byte Tailwind browser-runtime boundary.
- Declared the initial support status as `supported-opt-in`; provider activation remains explicit.
