# Changelog

All notable changes to `@xtend-material/core` are documented here.

## 0.1.0 - 2026-07-16

- Introduced the `xtend.material.design-kit.v1` CSS-and-metadata contract.
- Added 14 foundation, five shell and seven flow recipes under the semantic `xtm-*` namespace.
- Added enterprise and utility presentation packs with comfortable, compact and dense modes.
- Added the XTend token bridge, native CSS fallback and public Maraca preset.
- Added performance, browser, accessibility and anti-monkeypatching quality contracts.
- Declared the initial support status as `supported-opt-in`; XTend and Maraca defaults remain unchanged.
